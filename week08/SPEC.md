# 주차 요금 계산기 스펙

## 1. 개요

입차 시각과 출차 시각을 입력하면 주차 시간을 계산하고 요금을 산정한다. 계산 결과는 목록에 추가하며, 목록에 있는 항목을 삭제하면 오늘 받은 요금의 합계를 다시 계산한다.

## 2. 기술

- Python 3.10 이상
- Flet 1.0
- Python 표준 라이브러리 외의 패키지는 사용하지 않는다.
- 모델은 실습 서버의 `gemma4`만 사용한다.
- 화면 코드는 `main.py`에 작성한다.
- 계산과 입력 검증은 `logic.py`에 작성한다.
- `logic.py`는 Flet을 import하지 않는다.
- 테스트는 `test_logic.py`에서 실행한다.

## 3. 파일 구성

| 파일 | 내용 |
|---|---|
| `SPEC.md` | 프로그램의 동작 규칙과 테스트 표 |
| `logic.py` | 시각 검증, 주차 시간 계산, 요금 계산 |
| `test_logic.py` | `logic.py`의 함수 테스트 |
| `main.py` | Flet 화면, 계산 결과 목록, 삭제 및 합계 표시 |

## 4. 동작 규칙

### 4.1 시각 입력

- 시각은 정확히 `HH:MM` 형식으로 입력한다.
- `HH`는 `00`부터 `23`까지의 두 자리 숫자다.
- `MM`은 `00`부터 `59`까지의 두 자리 숫자다.
- 예: `09:30`은 올바른 입력이고 `9:30`, `0930`, `24:00`은 잘못된 입력이다.
- 빈 입력, `None`, 숫자가 아닌 입력은 잘못된 입력으로 처리한다.
- 잘못된 입력은 계산하지 않고 사용자에게 오류 문구를 보여 준다.

### 4.2 주차 시간

- 입차와 출차는 같은 날로 가정한다.
- 출차 시각은 입차 시각보다 반드시 늦어야 한다.
- 출차 시각이 입차 시각과 같거나 이르면 계산하지 않고 오류 문구를 보여 준다.
- 주차 시간은 입차부터 출차까지의 분 단위 정수로 계산한다.

### 4.3 요금

- 주차 시간 30분까지는 무료이며 요금은 `0원`이다.
- 30분을 초과한 시간만 과금 대상이다.
- 과금 대상 시간이 10분 단위로 나누어떨어지지 않으면 올림한다.
- 과금 단위 10분마다 500원이다.
- 요금은 다음 규칙으로 계산한다.

```text
초과 시간 = 주차 시간 - 30
과금 단위 수 = 초과 시간을 10분 단위로 올림
요금 = 과금 단위 수 × 500원
최종 요금 = 요금과 20,000원 중 작은 값
```

- 할인, 기본요금, 심야 할증은 적용하지 않는다.

### 4.4 계산 결과 목록

- 계산에 성공할 때마다 다음 정보를 한 항목으로 목록에 추가한다.
  - 입차 시각
  - 출차 시각
  - 주차 시간
  - 요금
- 입력 오류가 발생한 경우 목록에 추가하지 않는다.
- 각 목록 항목에는 삭제 버튼이 있다.
- 삭제하면 해당 항목을 목록에서 제거하고 합계를 다시 계산한다.
- 목록은 계산된 순서대로 표시한다.
- 목록이 비어 있으면 빈 목록을 표시하고 합계는 `0원`으로 표시한다.

### 4.5 금액 표시

- 금액은 천 단위마다 쉼표를 표시한다.
- 예: `0원`, `500원`, `20,000원`

## 5. 화면

- 창 하나짜리 Flet 프로그램으로 만든다.
- 입차 시각 입력창을 표시한다.
- 출차 시각 입력창을 표시한다.
- 계산 버튼을 표시한다.
- 오류 또는 안내 문구를 표시할 영역을 둔다.
- 계산 결과 목록을 표시한다.
- 각 결과 항목 옆에 삭제 버튼을 표시한다.
- 오늘 받은 요금의 합계를 목록 아래에 표시한다.
- 화면의 크기, 색상, 글자 크기는 기능을 해치지 않는 범위에서 자유롭게 정한다.

## 6. 테스트

`test_logic.py`는 다음 표의 모든 항목을 검사한다.

| 입력 | 기대 결과 |
|---|---|
| `09:00`, `09:00` | 오류 |
| `09:00`, `09:15` | `0원` |
| `09:00`, `09:30` | `0원` |
| `09:00`, `09:31` | `500원` |
| `09:00`, `09:40` | `500원` |
| `09:00`, `09:41` | `1,000원`에 해당하는 정수 `1000` |
| `09:00`, `09:50` | `1,000원`에 해당하는 정수 `1000` |
| `09:00`, `11:00` | `4,500원`에 해당하는 정수 `4500` |
| `09:00`, `19:00` | 최대 요금 `20,000원`에 해당하는 정수 `20000` |
| `9:00`, `09:30` | 오류 |
| `09:00`, `9:30` | 오류 |
| `24:00`, `24:10` | 오류 |
| `09:60`, `10:00` | 오류 |
| ``, `10:00` | 오류 |
| `09:00`, `` | 오류 |
| `09:00`, `08:59` | 오류 |
| `None`, `10:00` | 오류 |

테스트 실행 명령은 다음과 같다.

```powershell
python test_logic.py
```

테스트 파일은 실행이 끝났을 때 통과한 테스트 수와 실패한 테스트 수를 출력한다.

## 7. 완료 전 점검

- `python test_logic.py`가 모든 테스트를 통과한다.
- `logic.py`에 Flet import가 없다.
- 잘못된 입력이 목록에 추가되지 않는다.
- 30분 주차가 무료로 계산된다.
- 30분 초과분만 과금된다.
- 10분 미만의 나머지가 올림 처리된다.
- 요금이 20,000원을 초과하지 않는다.
- `main.py`는 계산식을 직접 구현하지 않고 `logic.py`의 함수를 호출한다.
- 목록 항목을 삭제하면 합계가 다시 계산된다.
- 금액에 천 단위 쉼표가 표시된다.

## 8. 하지 않는 것

- 자정을 넘기는 주차를 지원하지 않는다.
- 할인, 심야 할증, 회원 요금, 경차 요금을 지원하지 않는다.
- 데이터베이스나 파일 저장을 사용하지 않는다.
- 로그인과 사용자 계정을 지원하지 않는다.
- 외부 CSS 프레임워크나 다른 UI 프레임워크를 사용하지 않는다.
- 이번 과제에서 요구하지 않은 기능은 추가하지 않는다.
