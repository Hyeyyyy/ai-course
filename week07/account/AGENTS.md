## 앱 및 웹 개발 필수 준수 사항 가이드

성공적인 앱·웹 프로젝트 진행을 위해 기획, 디자인, 기술, 보안, 테스트 등 전 과정에서 준수해야 할 핵심 체크리스트입니다.

---

## 1. 기획 및 요구사항 정의
* **개발 요건 정의**: 화면 요건과 기능 요건을 상세히 정의한 문서를 명확히 작성하여 범위(Scope)를 설정합니다.
* **인포메이션 아키텍처(IA)**: 메뉴 구조와 사용자 이동 경로(User Flow)를 직관적으로 설계합니다.
* **일정 및 스프린트 계획**: 애자일 방법론 등을 활용해 개발 일정과 단계별 목표를 구체화합니다.

## 2. UI/UX 디자인 표준화
* **반응형 및 적응형 디자인**: 웹은 다양한 화면 크기(PC, 태블릿, 모바일)에 대응하고, 앱은 각 OS(iOS, 안드로이드) 가이드라인을 준수합니다.
* **직관적인 인터페이스**: 사용자가 헤매지 않도록 일관된 버튼 위치, 아이콘, 내비게이션 바를 제공합니다.
* **로딩 속도 최적화**: 이미지 압축 및 불필요한 그래픽 리소스를 줄여 초기 로딩 시 이탈률을 낮춥니다.

## 3.기술 스택 및 협업 프로세스
* **적정 기술 스택 선정**: 서비스의 성격과 확장성을 고려하여 프레임워크(예: React, Vue, Flutter, React Native 등)를 신중히 고릅니다.
* **버전 관리 시스템**: Git 등을 활용해 소스 코드를 체계적으로 관리하고 브랜치 전략(Git Flow 등)을 수립합니다.
* **협업 도구 활용**: Jira, GitHub Issues, Slack 등을 통해 버그, 진행 상황, 이슈를 투명하게 공유합니다.

## 4.보안 및 데이터 보호
* **HTTPS/TLS 적용**: 웹과 앱, 서버 간의 모든 통신 데이터를 암호화하여 패킷 탈취를 방지합니다.
* **개인정보 암호화**: 회원가입 및 로그인 시 민감한 정보(비밀번호 등)를 단방향 해시(SHA-256 등) 처리하여 안전하게 저장합니다.
* **접근 권한 관리(RBAC)**: 사용자 등급, 관리자 페이지 및 API 접근 권한을 철저히 분리하여 보안 사고를 예방합니다.

## 5. 테스트 및 배포
* **크로스 브라우징 및 기기 테스트**: 다양한 웹 브라우저(크롬, 사파리, 엣지)와 모바일 기기(iOS, 안드로이드 기종별)에서 레이아웃 및 기능 오류가 없는지 검증합니다.
* **앱 스토어 심사 정책 준수**: 구글 플레이스토어와 애플 앱스토어의 가이드라인(리젝 사유)을 미리 점검하고 대응합니다.

## 6. 코드 재사용성 (Reusability) 및 설계 표준
* **컴포넌트 기반 개발 (CBD)**: UI를 독립적이고 재사용 가능한 최소 단위(Atom/Molecule)로 쪼개어 웹과 앱(Hybrid/Cross-platform) 전반에서 돌려씁니다.
* **디자인 패턴 및 SOLID 원칙**: 단일 책임 원칙(SRP)을 준수하여 하나의 함수나 클래스는 단 하나의 역할만 수행하도록 작성합니다.
* **커스텀 훅(Custom Hooks) 및 유틸 함수 분리**: 비즈니스 로직이나 반복되는 데이터 페칭(Data Fetching) 로직은 별도 훅이나 모듈로 분리하여 UI 코드와 격리합니다.
* **디자인 시스템(Design System) 구축**: Figma와 개발 코드(Tailwind, Styled-components 등)의 토큰을 동기화하여 전사적인 스타일 재사용성을 극대화합니다.

## 7. 성능 최적화 (Optimization) 기법
* **컴포넌트 메모이제이션**: React의 `useMemo`, `useCallback`, `React.memo` 등을 활용해 불필요한 리렌더링을 방지합니다.
* **코드 분할 (Code Splitting)**: Lazy Loading을 적용하여 사용자가 당장 보지 않는 페이지나 컴포넌트는 나중에 다운로드하도록 처리해 초기 로딩 속도를 높입니다.
* **상태 관리 최적화**: 전역 상태(Zustand, Redux 등)와 서버 상태(TanStack Query 등)를 분리하여 불필요한 네트워크 요청을 줄이고 캐싱을 적극 활용합니다.
* **이미지 및 에셋 최적화**: 웹은 WebP/AVIF 포맷을 사용하고, 앱은 이미지 캐싱 라이브러리(Glide, Kingfisher 등)를 사용해 메모리 누수를 막습니다.
* **트리 쉐이킹 (Tree Shaking)**: 빌드 시스템(Webpack, Vite, Turbopack 등)을 설정하여 사용하지 않는 데드 코드를 최종 번들 파일에서 자동으로 제거합니다.
