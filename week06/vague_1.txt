전화번호를 어떤 형식으로 정리하고 싶으신가요? 보통 가장 많이 쓰이는 세 가지 패턴(**하이픈 제거, 하이픈 추가, 특정 형식 통일**)에 맞춰 파이썬(Python) 함수를 만들어 보았습니다.

### 1. 파이썬 코드 예시

```python
import re

def clean_phone_number(phone):
    """
    전화번호를 정리하는 함수
    1. 숫자 이외의 모든 문자 제거
    2. 010-1234-5678 또는 02-123-4567 형식으로 하이픈(-) 삽입
    """
    # 1. 숫자만 남기기 (정규표현식 사용)
    digits = re.sub(r'\D', '', str(phone))
    
    # 2. 길이에 따라 하이픈 넣기
    length = len(digits)
    
    if length == 8: # 서울 지역번호 (예: 02123456)
        return f"{digits[:2]}-{digits[2:]}"
    elif length == 10: # 지역번호 3자리 또는 010 뒤에 3자리/4자리 (예: 0212345678 또는 0101234567)
        # 02로 시작하는 경우와 010으로 시작하는 경우 구분 필요할 수 있음
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
        else:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 11: # 일반적인 휴대폰 번호 (예: 01012345678)
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 에러 처리
        return digits

# --- 테스트 코드 ---
test_numbers = [
    "01012345678",          # 기본 숫자형
    "010-1234-5678",        # 이미 하이픈 있는 경우
    "02.123.4567",          # 마침표 사용
    "010 1234 5678",        # 공백 사용
    "021234567",            # 9자리 (지역번호 포함)
    "(010)12345678",        # 괄호 사용
    "abc010-1234-5678def"   # 문자 섞임
]

print(f"{'원본':<20} | {'정리 후'}")
print("-" * 40)
for num in test_numbers:
    print(f"{num:<20} | {clean_phone_number(num)}")
```

---

### 2. 코드 설명

1.  **`re.sub(r'\D', '', str(phone))`**:
    *   `re` 모듈의 정규표현식을 사용합니다.
    *   `\D`는 '숫자가 아닌 모든 문자'를 의미합니다. 따라서 하이픈(`-`), 공백(` `), 괄호(`()`), 점(`.`) 등을 모두 제거하고 **순수하게 숫자만** 남깁니다.
2.  **길이 기반 분기 (`len(digits)`)**:
    *   **11자리**: 대부분의 휴대폰 번호 (`010-XXXX-XXXX`)
    *   **10자리**: 서울 지역번호(`02-XXX-XXXX`) 또는 일부 옛날 방식의 번호
    *   **8~9자리**: 짧은 지역번호 형태
3.  **F-string 사용**:
    *   `f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"`와 같이 슬라이싱을 이용해 원하는 위치에 하이픈을 넣어 가독성을 높였습니다.

### 3. 활용 팁

*   **데이터베이스(DB) 저장용**: 만약 DB에 저장할 목적이라면 하이픈을 다 빼고 **숫자만 저장**하는 것이 검색과 용량 면에서 효율적입니다. 그럴 때는 `re.sub(r'\D', '', phone)`만 사용하세요.
*   **엑셀/Pandas 활용**: 데이터가 많다면 위 함수를 Pandas의 `.apply()` 메서드와 결합하여 수만 개의 전화번호를 한 번에 바꿀 수 있습니다.
    ```python
    df['phone'] = df['phone'].apply(clean_phone_number)
    ```

혹시 다른 특정 형식(예: 국가코드 `+82` 추가 등)이 필요하시면 말씀해 주세요!
