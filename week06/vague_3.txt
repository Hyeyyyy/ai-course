전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 흔히 쓰이는 **1) 하이픈(-) 제거**, **2) 표준 형식(010-0000-0000)으로 변환**, **3) 숫자만 추출**하는 세 가지 버전을 파이썬(Python) 코드로 만들어 보았습니다.

### 1. 파이썬 코드 예시

```python
import re

def clean_phone_number(phone):
    """
    전화번호를 입력받아 숫지만 추출한 뒤, 
    표준적인 '000-0000-0000' 형식으로 반환합니다.
    """
    # 1. 숫자 이외의 모든 문자 제거 (하이픈, 공백, 괄호 등 제거)
    digits = re.sub(r'\D', '', phone)
    
    # 2. 번호 길이에 따른 처리
    length = len(digits)
    
    if length == 8:
        # 지역번호가 없는 8자리 번호 (예: 일반 전화)
        return f"{digits[:3]}-{digits[3:]}"
    
    elif length == 10:
        # 02-123-4567 또는 010-123-4567 형태
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
            
    elif length == 11:
        # 010-1234-5678 형태 (가장 일반적)
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    
    else:
        # 형식이 맞지 않는 경우 숫자만 반환하거나 에러 처리
        return digits

# --- 테스트 코드 ---
test_numbers = [
    "01012345678",          # 숫자만 있는 경우
    "010-1234-5678",        # 이미 하이픈이 있는 경우
    "02 123 4567",          # 공백이 있는 경우
    "(010)12345678",        # 괄호가 있는 경우
    "02-123-4567",          # 서울 지역번호 10자리
    "031-123-4567",         # 경기도 지역번호 10자리
    "abc12345678def"        # 문자가 섞인 경우
]

print(f"{'원본':<20} | {'정리된 번호'}")
print("-" * 40)
for num in test_numbers:
    print(f"{num:<20} | {clean_phone_number(num)}")
```

### 2. 코드 설명

1.  **`re.sub(r'\D', '', phone)`**: 정규 표현식을 사용하여 숫자가 아닌 모든 문자(`\D`)를 빈 문자열로 바꿉니다. 즉, `010-1234-5678`, `010 1234 5678`, `(010)12345678` 모두 `01012345678`로 통일됩니다.
2.  **조건문 (`if-elif`)**:
    *   **11자리**: 휴대폰 번호(`010-XXXX-XXXX`)로 판단하여 처리합니다.
    *   **10자리**: 
        *   앞자리가 `02`(서울)이면 `02-XXX-XXXX` 형식으로 만듭니다.
        *   그 외 지역번호(031, 051 등)라면 `0XX-XXX-XXXX` 형식으로 만듭니다.
    *   **8자리**: 짧은 번호의 경우 간단히 구분합니다.
3.  **유연성**: 입력값에 문자가 섞여 있어도 숫자만 골라내기 때문에 매우 안전합니다.

### 활용 팁
*   **엑셀 데이터 정리 시**: 파이썬의 `pandas` 라이브러리를 사용 중이라면, `df['phone'].apply(clean_phone_number)` 한 줄로 수만 개의 데이터를 순식간에 정리할 수 있습니다.
*   **데이터베이스 저장 시**: 보통 DB에는 하이픈 없이 숫자만 저장하는 것이 검색과 관리에 유리하므로, 위 함수에서 `return digits` 부분만 사용하여 숫자만 추출해 저장하는 방식을 추천합니다.
