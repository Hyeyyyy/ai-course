전화번호를 어떤 형식으로 정리하고 싶으신가요? 상황에 따라 가장 많이 쓰이는 세 가지 패턴(하이픈 추가, 숫자만 추출, 특정 형식 통일)을 기준으로 파이썬(Python) 함수를 만들어 보았습니다.

### 1. 숫자만 남기고 하이픈(`-`) 형식으로 만들기
사용자가 `01012345678`, `010-1234-5678`, `010 1234 5678` 등 어떤 식으로 입력해도 `010-1234-5678`로 통일해주는 함수입니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자 이외의 모든 문자를 제거
    digits = re.sub(r'\D', '', str(phone_str))
    
    # 2. 길이에 따라 하이픈 삽입
    length = len(digits)
    
    if length == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567 형식
        # 앞 3자리가 02이면 2자리로 처리할 수도 있지만, 일반적인 모바일/지역번호 대응
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9:  # 02-1234-5678 형식 (서울 지역번호 등)
        return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
    else:
        # 형식이 맞지 않으면 원래 숫자만 반환하거나 에러 메시지
        return digits

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "010 1234 5678", "021234567", "0101234567"]

for num in test_numbers:
    print(f"{num}  =>  {format_phone_number(num)}")
```

### 2. 단순히 숫자만 추출하기 (데이터 정제용)
DB에 저장하거나 검색용으로 사용할 때, 기호 없이 숫자만 깔끔하게 뽑아내는 함수입니다.

```python
import re

def extract_digits(phone_str):
    return re.sub(r'\D', '', str(phone_str))

# 테스트
print(extract_digits("010-1234-5678")) # 결과: '01012345678'
print(extract_digits("(02) 123-4567")) # 결과: '021234567'
```

### 3. 리스트 형태의 전화번호 일괄 정리하기
여러 개의 번호가 들어있는 리스트를 한 번에 변환할 때 유용합니다.

```python
def clean_phone_list(phone_list):
    return [format_phone_number(num) for num in phone_list]

# 테스트
raw_data = ["01012345678", "021234567", "010-9876-5432", "010 1111 2222"]
cleaned_data = clean_phone_list(raw_data)

print(cleaned_data)
# 출력: ['010-1234-5678', '02-123-4567', '010-9876-5432', '010-1111-2222']
```

### 💡 코드 설명 및 팁
1.  **`re.sub(r'\D', '', str(phone_str))`**: 정규표현식을 사용하여 숫자가 아닌 것(`\D`)을 모두 찾아 빈 문자열(`''`)로 바꿉니다. 즉, 숫자만 남깁니다.
2.  **조건문 (`if-elif`)**: 한국 전화번호 체계는 길이에 따라 하이픈 위치가 달라집니다. 
    *   11자리: `3-4-4` 구조
    *   10자리: `3-3-4` 또는 `2-4-4` 구조
    *   9자리: `2-4-3` 구조
3.  **확장성**: 만약 해외 전화번호(국가코드 포함)까지 처리해야 한다면 훨씬 복잡한 로직이 필요하므로, 위 코드는 **한국 내수용 데이터 정리**에 최적화되어 있습니다.
